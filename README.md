# STM32G431 PMSM FOC 三环闭环控制系统

基于 STM32G431 的永磁同步电机（PMSM）有感磁场定向控制（FOC）系统。

项目从底层 PWM、电流采样和编码器反馈链路出发，逐步实现 SVPWM、电流环 PI、速度环 PI 和位置闭环控制，并针对 ADC 采样窗口、电流采样异常、控制器积分饱和等问题进行分析和验证。

项目采用逐阶段开发和实验验证的方式完成，记录了从理论分析、外设配置、控制算法实现到实际电机调试的完整过程。

## 2. 系统控制架构

系统采用位置环、速度环、电流环的级联控制结构。

控制链路：

```
位置目标
   │
   ▼
位置控制器
   │
   ▼
目标转速
   │
   ▼
速度 PI
   │
   ▼
Iq_ref ──────────── Id_ref
   │                   │
   ▼                   ▼
Iq PI                Id PI
   │                   │
   ▼                   ▼
Uq                  Ud
   │                   │
   └─────────┬─────────┘
             ▼
        逆 Park 变换
             │
             ▼
           SVPWM
             │
             ▼
      TIM1 互补 PWM
             │
             ▼
       三相功率逆变器
             │
             ▼
          PMSM
```

反馈链路：

- **电流反馈**：ADC 同步采样 → 相电流重构 → Clarke 变换 → Park 变换 → Id/Iq
- **位置反馈**：TIM2 编码器计数 → 机械角度 → 电角度 → FOC 坐标变换
- **速度反馈**：编码器位置增量 → 机械转速 → 速度环 PI

内环负责电流快速调节，外环分别实现速度和位置控制。

## 3. 核心功能实现

### 3.1 三相 SVPWM 与互补 PWM

基于 STM32G431 TIM1 高级定时器，实现三相互补 PWM 输出。

- 20 kHz 中心对齐 PWM
- 三组互补输出及死区配置
- SVPWM 扇区判断
- 有效矢量作用时间计算
- 三相占空比更新
- TIM1 Break 输出保护

通过开环旋转电压矢量实验，验证 SVPWM 输出链路和电机旋转方向。

### 3.2 编码器位置反馈与电角度校准

使用 TIM2 编码器模式读取 AB 相正交信号，获得电机机械位置和旋转方向。

实现内容：

- 编码器计数与方向识别
- 单圈机械角度计算
- 机械角度与电角度换算
- 电角度零点校准
- 转速估算

通过施加已知方向的定子磁场，建立编码器角度与转子磁链方向之间的对应关系。

利用 dq 坐标系中的电流表现，对电角度校准结果进行实验验证。

### 3.3 PWM 同步电流采样

使用 TIM1 TRGO2 触发 ADC 注入组转换，实现与 PWM 同步的电流采样。

主要实现：

- TIM1 与 ADC 硬件触发同步
- ADC 注入组转换
- 电流采样零点校准
- ADC 原始值转换为实际电流
- 双电阻采样及三相电流重构
- Clarke/Park 坐标变换

重点分析低侧 MOSFET 导通时间、采样建立时间及 ADC 转换时间对有效采样窗口的影响。

### 3.4 ADC 采样窗口检查与 Break 保护

实际调试中发现，当控制器输出电压增大、PWM 占空比发生变化时，可用电流采样窗口可能缩短。

如果继续使用不满足采样时序要求的数据进行电流闭环控制，可能导致电流反馈失真，进一步影响 PI 控制器输出。

针对这一问题，实现：

- 根据 PWM 比较值判断采样窗口有效性
- 对采样建立时间和 ADC 转换时间进行预算
- 采样窗口异常状态检测
- 通过 TIM1 Break 停止 PWM 输出

实验中验证了采样窗口异常时停止 PWM 的保护行为。

### 3.5 Id/Iq 双电流环 PI 控制

基于 Clarke/Park 变换获取 d/q 轴电流，实现两个独立的 PI 电流控制器。

实现内容：

- Id/Iq 电流反馈
- d/q 轴 PI 调节
- PI 参数与目标带宽计算
- 电压矢量幅值限制
- 条件积分抗饱和
- 电流环阶跃响应测试

调试过程中通过 VOFA+ 观察 Id、Iq、Ud、Uq 等变量，分析不同 PI 参数对响应速度和稳定性的影响。

### 3.6 速度环与位置环

在 20 kHz 电流环基础上，增加速度和位置外环。

速度环：

- 编码器转速反馈
- 1 kHz 速度 PI 控制
- 输出 Iq 电流参考值
- 与电流内环组成级联闭环

位置环：

- 编码器机械位置反馈
- 目标位置控制
- 通过速度环、电流环驱动电机运动
- 位置目标阶跃测试

完成 10° 与 90° 两个目标位置之间的切换测试，电机运动方向符合预期。

## 4. 上位机波形监控

使用 VOFA+ 配合 LPUART1 和 DMA 实现运行数据的实时传输与可视化。

主要监控变量包括：

- 三相电流
- Id / Iq
- Id_ref / Iq_ref
- Ud / Uq
- 编码器机械角度
- 电机速度
- 采样窗口有效性状态

上位机数据传输采用 JustFloat 格式，实验中使用最高 4 kHz 的监控发送频率。

通过波形观察分析电流环响应、运行状态和异常现象。

## 7. 工程使用说明

项目使用 STM32CubeIDE 开发。

基本使用流程：

1. 克隆或下载仓库。
2. 使用 STM32CubeIDE 导入现有工程。
3. 检查硬件接线、供电配置和外设参数。
4. 编译固件并下载至 STM32G431。
5. 连接电机驱动板和编码器。
6. 在确认供电限制及保护配置正确后进行实验。

**注意：** 三相逆变器涉及电机功率驱动。不同硬件、电机参数和采样电路可能需要重新配置 PWM、采样时序、电流限幅及保护阈值，不建议在未经检查的情况下直接使能功率输出。

## 9. 项目总结

本项目从 STM32 定时器、ADC、编码器等底层外设出发，逐步构建完整的 PMSM FOC 控制链路。

开发过程中不仅关注控制算法本身，也重点分析 PWM 时序、ADC 采样条件、电角度校准、PI 参数和输出限幅之间的关系，并通过实际波形与保护实验验证相关问题。

项目主要用于电机控制算法、STM32 底层外设及嵌入式实时控制系统的学习与工程实践。
